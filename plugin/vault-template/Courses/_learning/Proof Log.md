# Proof Log

One line per proof attempt on the proof track, appended by `/learn:teach <course> proofs` in this format:

`- [date:: YYYY-MM-DD] [course:: CODE] [proof:: Proof - Note Name] [stage:: 2] [result:: pass] Where it broke: ...`

- **Stage** is the scaffold stage attempted: 1 step by step, 2 name the chain of moves then write, 3 from the key line, 4 solo.
- **Where it broke:** the first step that went wrong or needed help, in a sentence ("none" on a clean pass). The engine schedules the next attempt; this log keeps what went wrong.
- **Format rules:** plain names, not links. Maths is LaTeX. Old lines are never edited.
