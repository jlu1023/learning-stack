# Set Operations

A note from a **reference course** (PRE100, listed under `reference_courses` in `vault-learning.yaml`): earlier material that later courses build on. It gets no roadmap and is never quizzed; it appears in other courses' roadmaps as an external prerequisite.

> [!definition]
> For subsets $A, B$ of a set $\Omega$: the **union** $A \cup B = \{x \in \Omega \mid x \in A \text{ or } x \in B\}$, the **intersection** $A \cap B = \{x \in \Omega \mid x \in A \text{ and } x \in B\}$, the **complement** $A^c = \{x \in \Omega \mid x \notin A\}$ and the **difference** $B \setminus A = B \cap A^c$. $A$ and $B$ are **disjoint** if $A \cap B = \emptyset$.
