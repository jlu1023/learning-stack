About Study Desk

A quiet window onto the learn plugin. The tutor is Claude Code running in your study folder, exactly as in the terminal, with maths typeset. Study Desk is an independent, open-source add-on; it is not made or endorsed by Anthropic.

Sidebar

Home shows every course: how many ideas are started, due for review and waiting as Error Log redos. Course tabs are compartments, each with its own conversation; the number is what is due. General is for anything else. Conversations are not saved between launches. « hides the sidebar, » brings it back.

Working

Type at the ❯ prompt and press Enter (Shift+Enter for a new line). The plugin's commands work as in the terminal, with your own course code in place of COURSE101:

/learn:teach COURSE101 next teach the next idea
/learn:teach COURSE101 resume pick up an open session
/learn:quiz COURSE101 review what is due
/learn:quiz mixed all courses mixed
/learn:teach COURSE101 proofs proof track
/learn:teach COURSE101 test unit test
/learn:primer COURSE101 next overview of the next unit
/learn:primer week the week ahead
/learn:roadmap COURSE101 redraw the roadmap
/clear forget this tab's conversation
/model opus /effort high change model or effort (or use the menus under the prompt)
/usage show your limits

Paste or drop a photo of handwritten working to have it read. You can keep typing while it answers: messages queue and are sent in turn. Press Esc to stop a reply (queued messages come back to the prompt). While it works, the line under the prompt shows what it is doing and for how long; each reply notes how long it thought.

The tutor cannot show Claude Code's question boxes here, so it asks every question as plain text and waits for your typed reply.

Permissions

The tutor runs Claude Code in your study folder in permission mode . In auto, the default, Claude Code decides for itself which actions are safe and carries them out without stopping to ask you: it reads and edits files and runs commands in that folder, because this window cannot show its permission prompts. To change it, start Study Desk with --permission-mode acceptEdits (or manual, dontAsk or plan), or set "permission_mode" in config.json in the data folder named below. In those stricter modes anything Claude Code would normally ask about is refused rather than asked, so first allow the engine command in the folder's Claude Code settings (SETUP.md, Permission prompts) or the tutor cannot record your results.

Notes and the side panel (Ctrl+.)

Click any underlined concept and its note opens as a tab along the top, grouped under the course like a browser tab group; the first tab is always the tutor. Close a tab with × or a middle click. Shift+click a concept to read it in the side panel beside the chat instead (Note). Units: progress per lecture, week or module, with its overview. Due: what is due in this course (opening a note shows the answer).

Colours

Bars: red learning, amber secure, green mastered, grey unseen. Course colours come from a built-in palette; change them under Style.

Usage

The line under the prompt shows the model, the effort and your Claude 5-hour and weekly limits, as in the terminal; the sidebar shows the same limits as bars. They update after each reply. The small line under the prompt shows the size of the last reply and of the conversation.

Style

Themes, every colour, course colours, font, text and maths size, column width, and the academic paper layout.

Keys

Ctrl+0 Home · Ctrl+1 to 9 tabs · Alt+← and Alt+→ previous and next note tab · Alt+W close note tab · Ctrl+B sidebar · Ctrl+. side panel · F11 fullscreen (Esc leaves it) · Esc stop or close
